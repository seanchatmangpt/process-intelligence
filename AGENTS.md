# Agent Operating Contract

Scope: this repository, unless a deeper `AGENTS.md` narrows a subtree. Live tree evidence outranks stale prose. Nested rules may tighten constraints but may not silently weaken evidence, authority, replay, or publication law.

## Preserve → Fence → Calculus

Resolve repo/ref/base to an exact commit. Read applicable root+nested doctrine, README/architecture docs, manifests, task runners, CI, generated-source policy, and release policy before editing. Preserve interfaces, canonical/generated boundaries, authority, receipts/replay, compatibility, and maximal reversible lawful options. Apply Chesterton's fence before deleting a boundary; replace stale doctrine with a narrower executable rule and falsifier.

Use objects/morphisms with explicit admission, closure, authority, actuation, receipt, replay, and standing. One failed edge is topology, not graph failure.

## Evidence

Use `UNKNOWN | PARTIAL_ALIVE | ALIVE | BLOCKED | BUILD_BROKEN | UNSUPPORTED` plus typed `REFUSED_*`. `UNKNOWN` is not admitted; `UNSUPPORTED` is not refused; checkpoint is not crown. `ALIVE` requires observed execution against the exact admitted subject. Track observed/admitted/executed/changed/verified/inferred/refused/blocked/unsupported separately. Inspection != execution; workflow != successful run; connector object != mounted tree; named receipt != replay-verified receipt.

## Manufacture / authority

`A = μ(O*)`; `R = receipt(A)`. `O*` is admitted, aligned, grounded, bounded observation; `R` binds identity, authority, consequence, replay, standing. Separate `SELECT`, `CONSTRUCT`, `DO`. Raw input, model/planner/generator/proof/hook output has no ambient execution authority. Hooks manufacture intents, never actuate. Consequential `DO` must use the repository's authorized receipt-bearing boundary: zero unreceipted actuation.

## Work

Follow `parse → orient → resolve → materialize → read doctrine → inspect → admit/refuse → diagnose/repair → construct → actuate → receipt → replay/hook → standing`.

Orient transports, permissions, mounts/checkouts, Git, connectors/auth/network, archives/artifacts, runtimes, compilers, packages, and tests. Connector visibility is not materialization. Never silently move the admitted base. Prefer the existing lawful path and smallest coherent bounded diff; do not build parallel architecture when a lawful path can be repaired. Generated artifacts are projections: edit the owning ontology/graph/query/schema/template/generator. No fabricated evidence, weakened tests, unrelated refactors, acceptance mocks, or unresolved placeholders on changed production paths.

## Verify

Acceptance precedence: exact user command/behavior → documented repo command → narrowest existing equivalent. Run cheapest high-information gates first, then unit → integration/protocol → e2e → release/qualification as affected. On failure preserve command/exit/diagnostic, locate the failed transition, form a new hypothesis, repair narrowly, encode a permanent guard/test/refusal/fixture/schema/theorem, then rerun that boundary. Never rerun an unchanged failure without a new hypothesis. Hosted CI supplements local proof; it is not truth.

Unless explicitly instructed otherwise: purpose branch from exact base, intentional commit, non-force push, draft PR, no merge. Inspect exact published head and CI; status metadata is not logs. Final receipt states repo/base/tree, O/O*, transports/failures, μ/changes/generated status, commands/exits, verification ladder, receipt/replay, branch/SHA/PR, scoped standing, and falsifiers.
