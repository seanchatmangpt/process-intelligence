\subsection{Tests}
\label{sec:blue-river-dam-evidence-tests}

The test suite in \texttt{src/lib.rs} contains 8 test functions organized in
the \texttt{\#[cfg(test)] mod tests} block. Five were present at receipt time
(certified 5/5 passing); three were added post-receipt.

\textbf{Receipt-certified tests (5/5 passing as of 2026-06-01):}
\begin{description}
  \item[\texttt{test\_governance\_hierarchy}] Verifies that
    \texttt{Governor::new()} produces a struct with
    \texttt{authority\_id == "ostar-governor"}.
  \item[\texttt{test\_lifecycle\_state\_machine}] Verifies that
    \texttt{BlueRiverDamOrchestrator::new()} initializes in
    \texttt{LifecycleState::Design}.
  \item[\texttt{test\_quality\_gate\_soundness}] Verifies that
    \texttt{gate\_1\_soundness()} returns \texttt{passes: true} and the
    expected gate name string.
  \item[\texttt{test\_conformance\_metric}] Verifies that a
    \texttt{ConformanceMetric} struct is constructible with \texttt{fitness:
    0.95}.
  \item[\texttt{test\_mape\_k\_knowledge\_persistence}] Verifies that
    \texttt{Knowledge::new()} initializes \texttt{reference\_model} as
    \texttt{"sound\_wf\_net"}.
\end{description}

\textbf{Post-receipt tests (pass/fail status not captured in any receipt):}
\begin{description}
  \item[\texttt{test\_validate\_wf\_net\_soundness}] Tests the BFS/DFS soundness
    algorithm across three cases: a valid WF-net, a two-source unsound net, and
    a net with an unreachable node. This is the most substantive structural
    test in the suite.
  \item[\texttt{test\_compute\_fitness\_genuine}] Tests LCS-based fitness
    computation for a perfect trace (fitness 1.0, alignment moves 0), a partial
    trace (fitness 2/3, alignment moves 1), and an empty trace (fitness 0.0,
    alignment moves 3).
  \item[\texttt{test\_mape\_k\_cycle\_execution}] Tests the full
    \texttt{mape\_k\_cycle()} path from \texttt{Design} through
    \texttt{Simulation} to \texttt{Monitoring}, ingesting a compliant event
    stream and verifying the cycle completes without \texttt{OrchestrationRefusal}.
\end{description}

The compiled ARM64 test binary at
\texttt{target/debug/deps/blue\_river\_dam-89f933de4cf483d1}
(1{,}272{,}256 bytes, executable) confirms that at least one full test
compilation has succeeded on the native platform.
