\subsection{Tests}
\label{sec:otel-weaver-exp-002-diff-to-residual-evidence-tests}

Two test surfaces are relevant to EXP-002:

\paragraph{test\_bridge\_translation\_equivalence (inline unit test)}
Location: \texttt{src/bridge.rs}, \texttt{\#[cfg(test)] mod tests} block.

This test constructs a \texttt{TelemetryFeedstockS2} record with:
\begin{itemize}
    \item \texttt{instance\_id = "inst-001"}
    \item \texttt{transition\_name = "approve\_loan"}
    \item \texttt{token\_color = Some("red")}
    \item \texttt{witness\_hash = "blake3\_signature\_data\_here"}
\end{itemize}
It passes the record through \texttt{BridgeRx::new().translate()}, then asserts:
\begin{itemize}
    \item \texttt{s1\_telemetry.instance\_id == "inst-001"} (identity preserved)
    \item \texttt{s1\_telemetry.activity\_name == "approve\_loan"} (rename applied)
    \item \texttt{s1\_telemetry.witness\_hash == "blake3\_signature\_data\_here"}
          (hash preserved)
\end{itemize}

The test does not assert any behavior regarding \texttt{token\_color}, confirming
that the field is silently dropped. No cargo test transcript for this test in
isolation is present in the repository. The test is declared and the code compiles
(based on materialized \texttt{target/debug/deps} artifacts), but whether this
specific test was executed and passed in isolation is not documented by an
experiment-level receipt.

\subsection{ALIVE/PARTIAL/BLOCKED Status}
\label{sec:otel-weaver-exp-002-diff-to-residual-evidence-status}

\textbf{Current status: PARTIAL.}

EXP-002 cannot be declared ALIVE because the following gate criteria are unmet:

\begin{enumerate}
    \item \textbf{Isolated test transcript}: No \texttt{cargo test} output transcript
          for \texttt{test\_bridge\_translation\_equivalence} in isolation exists
          inside the exp-002 directory or any exp-002-specific receipt file. The
          parent-suite checkpoint contains a transcript for
          \texttt{test\_weaver\_integration\_synthesis} but not the unit test.

    \item \textbf{Confirmed build artifact}: While \texttt{target/debug/deps} shows
          compiled dependency rlibs (\texttt{serde}, \texttt{serde\_yaml}, etc.),
          the \texttt{bridge} rlib itself does not appear in the materialized
          artifact list, suggesting the library may not have been fully compiled to
          a linkable artifact in isolation.

    \item \textbf{Documented loss semantics}: The \texttt{token\_color} field is
          dropped silently during \texttt{translate()} with no \texttt{LossReport}
          receipt documenting the loss as intentional. The doctrine file
          \texttt{otel-weaver-is-feedstock.md} requires that every projection of
          telemetry generate a \texttt{LossReport}.

    \item \textbf{Ontology surface}: No TTL/RDF surface exists for the S1/S2 schema
          types or the \texttt{BridgeRx} translation semantics.
\end{enumerate}

The evidence that is present (source code, inline test declaration, parent-scope
checkpoints, doctrine files, mapping YAML) is sufficient to establish that the
experiment was designed correctly and its core translation logic is sound. The
missing items are execution transcripts, loss documentation, and ontology
integration rather than architectural defects. The PARTIAL verdict stands until
all four criteria above are met and a new exp-002-scoped checkpoint is issued.
