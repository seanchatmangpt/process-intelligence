\subsection{Tests}
\label{sec:sources-papers-evidence-tests}

The paper corpus does not directly own test fixtures. Tests that verify the
type-law obligations derived from the paper corpus are located in
\texttt{wasm4pm-compat/tests/ui/} and are run via \texttt{cargo test --test ui}
(trybuild). The paper corpus documents specify which fixtures are required;
\texttt{PAPER\_TO\_BOARD\_CLAIM.md} names each fixture as part of the evidence
path for board claims.

Named compile-fail fixtures required by and cross-referenced from the paper
corpus include:

\begin{itemize}
  \item \texttt{wfnet\_forged\_soundness.rs} + \texttt{.stderr} --- rejects
    \texttt{WfNetConst<true>} construction without \texttt{WfNetSoundnessWitness}
    (van der Aalst 1998).
  \item \texttt{petri\_place\_to\_place\_arc.rs} and
    \texttt{petri\_transition\_to\_transition\_arc.rs} --- reject bipartite
    arc violations (Murata 1989 \S2).
  \item \texttt{ocel\_e2o\_missing\_link.rs} and \texttt{ocel\_o2o\_missing\_link.rs}
    --- reject OCEL 2.0 logs with missing link types (van der Aalst et al.\ 2023).
  \item \texttt{xes\_not\_object\_centric.rs} --- rejects XES-to-object-centric
    projection without explicit \texttt{LossPolicy} (IEEE 1849-2023).
  \item \texttt{declare\_unary\_constraint.rs} --- rejects single-activity
    DECLARE instantiation (Pesic \& van der Aalst 2006).
\end{itemize}

Named compile-pass fixtures required include:
\begin{itemize}
  \item \texttt{wfnet\_with\_soundness\_witness.rs} --- confirms the lawful
    construction path is open.
  \item \texttt{ocel\_event\_object\_relation.rs} and
    \texttt{ocel\_object\_object\_relation.rs} --- confirm lawful OCEL 2.0
    link construction.
\end{itemize}

No test fixtures exist for adversarial admission gate enforcement (BLAKE3
receipt verification) --- this is an open gap, documented in the PARTIAL status.

\subsection{ALIVE/PARTIAL/BLOCKED Status}
\label{sec:sources-papers-evidence-status}

\textbf{Status: PARTIAL.}

The project holds PARTIAL status because two independent gate criteria remain
unmet despite the PAPER\_CANON\_RECEIPT being sealed with zero gaps:

\begin{enumerate}
  \item \textbf{Inductive Miner execution gap (P0).} The Inductive Miner
    algorithm is confirmed MISSING from wasm4pm as of 2026-05-31
    (\texttt{INDUCTIVE\_MINER\_ANALYSIS.md}). All board claims about ``sound
    algorithm discovery'' are currently unattested. The Heuristics Miner
    substitute present in wasm4pm does not produce a \texttt{ProcessTree} and
    does not guarantee soundness; it does not substitute for Inductive Miner.

  \item \textbf{Adversarial implementation gap.} The adversarial canon
    (\texttt{adversarial-canon.md}) documents Byzantine-fault-tolerant
    discovery requirements (Sybil-resistant BLAKE3 receipt verification,
    non-deterministic reality receipt handling, typestate progression
    enforcement) but no implementation evidence exists in wasm4pm or
    wasm4pm-compat. The gap between the theoretical requirement and runtime
    support is unverified.

  \item \textbf{Alpha Miner output type audit (P0, unconfirmed).} The
    \texttt{ALPHA\_MINER\_ANALYSIS.md} identifies a P0 open question: whether
    \texttt{wasm4pm-algos/src/alpha.rs} incorrectly types its output as
    \texttt{WfNetConst<Sound>} when it has not verified soundness. This audit
    has not been confirmed resolved.

  \item \textbf{22 named missing types.} The type-law obligation backlog in
    \texttt{PAPER\_TO\_TYPE\_LAW.md} lists 22 named missing types across 10
    PARTIAL papers. Until fulfilled, 5 board claims explicitly listed in
    \texttt{PAPER\_TO\_BOARD\_CLAIM.md} are NOT board-admissible.
\end{enumerate}

The PARTIAL status is the correct, accurate, and permanent record. ALIVE
certification for the paper corpus project requires all named P0 gaps to be
resolved and receipted, not merely documented.
