\subsection{Commands}
\label{sec:comparisons-impl-commands}

The comparisons corpus does not specify executable commands or a build pipeline.
Its documents are authored directly as markdown under the v30.1.1 research
protocol. The wasm4pm conformance authority module that implements the type-law
architecture described in this corpus was compiled and tested with:

\begin{verbatim}
cargo check  (wasm4pm v26.5.29)
\end{verbatim}

yielding \texttt{Finished `dev` profile [unoptimized + debuginfo] target(s) in 4.10s}
with 0 errors. The eight unit tests in \texttt{conformance\_authority} all passed,
as recorded in \texttt{receipts/wasm4pm\_conformance\_authority\_generation.md}.

\subsection{Data and Ontology Surfaces}
\label{sec:comparisons-impl-ontology}

The RDF ontology surface for the comparisons corpus is
\texttt{ggen/wasm4pm-compat.ttl}, which provides RDF-grounded witness markers
aligned to named papers. The ontology encodes the \texttt{WitnessMarker}
vocabulary (\texttt{Ocel20}, \texttt{Xes1849}, \texttt{WfNetSoundnessPaper},
\texttt{VanDerAalst1998}, etc.) as RDF resources, making the paper-to-type-law
mapping machine-readable and SPARQL-queryable.

The OCPQ query language, defined in \texttt{wasm4pm-compat/src/ocpq.rs}, is the
most novel data surface in the corpus: \texttt{ObjectScope}, \texttt{Predicate}
tree, and \texttt{OcpqQuery} constitute a wasm4pm-compat-original query language
with no evaluation engine in any current stack (FUTURE WORK).
