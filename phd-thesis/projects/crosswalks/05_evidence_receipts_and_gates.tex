\section{Evidence, Receipts, and Gates}
\label{sec:crosswalks-evidence}

\subsection{Tests}
\label{sec:crosswalks-evidence-tests}

No test fixtures exist in the \texttt{crosswalks/} directory. The crosswalk documents define
Rust struct definitions and step transition functions for witness automata, but no compilation
evidence confirms that these definitions are present in the actual \texttt{wasm4pm-compat} crate.
The \texttt{pm4py\_to\_wasm4pm\_data\_types.md} defines \texttt{OcelEventLog},
\texttt{XesTrace}, \texttt{ActivityName}, \texttt{Timestamp}, and \texttt{ResourceId} as Rust
structs with constructor invariants, but no round-trip verification test or cargo test output
is present in the crosswalks source directory (source: evidence extraction, open questions).

The \texttt{declare\_to\_wasm\_mapping.md} defines four witness automata with concrete step
transition functions and lattice join operators. These are research-level specifications; no
compiled test confirms the lattice join produces a \texttt{LatticeViolation} on contradiction
in the actual runtime. The \texttt{bpmn\_to\_declare\_conformance.md} defines \textsc{LTLf}-to-lattice
mappings with formal witness transition functions; no Rust implementation evidence is cited.

\textbf{Status:} No passing tests attributable to the crosswalks project can be cited. This
is a structural gap, not a test failure: the tests have not been written, not failed.

\subsection{Receipts}
\label{sec:crosswalks-evidence-receipts}

The \texttt{project\_manifest.yaml} records \texttt{receipt\_present: false}. The
\texttt{ggen-unified-emitted-artifact-census.md} assigns a \textsc{CROSSWALK\_RECEIPT} to the
directory but describes it as ``implicit; per-crosswalk dating'' --- meaning the receipt is
inferred from the file modification timestamps of the eight documents, not computed as an
explicit \textsc{BLAKE3} hash chain.

The \texttt{receipts/RECEIPT\_REGISTRY.md} contains seven canonical research program receipts.
None of the seven is specifically attributed to the \texttt{crosswalks/} directory as a receipt
holder. The receipts in \texttt{receipts/} that are relevant to the crosswalks domain are:

\begin{itemize}
  \item \texttt{rec\_residual\_standard\_005.json} --- standards residual analysis (related to
        \textsc{ISO} mapping in \texttt{alive\_001\_to\_iso\_compliance.md})
  \item \texttt{rec\_risk\_compliance\_004.json} --- risk and compliance surface (related to
        cryptographic binding requirements)
\end{itemize}

No explicit receipt binding the crosswalks directory as a unit exists. The absence is a known
gap documented in \texttt{project\_manifest.yaml}.
