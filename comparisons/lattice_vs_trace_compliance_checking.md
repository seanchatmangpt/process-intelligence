# Methodology Comparison: Lattice-Based vs. Trace-Based Compliance Checking

Comparison of verification guarantees between lattice-based alignment witnesses and traditional trace-based sequence matching under the v30.1.1 standard.

| Metric | Lattice-Based (Axiom 2 Monotonicity) | Trace-Based (Standard Replay) |
|---|---|---|
| **Online Verification** | Yes (eager evaluation at each event) | No (typically requires complete trace) |
| **Tamper Resistance** | High (witness state hash chained using BLAKE3) | Low (easy to inject silent intermediary steps) |
| **State Complexity** | Bounded by lattice width | Unbounded (grows with trace length) |
| **Conflict Resolution** | Explicit (joins to $\top$) | Implicit (results in low fitness rating) |
| **Mathematical Proofs** | Soundness and completeness verified | Heuristic alignment optimization |

## 1. Mathematical Formulation of Lattice-Based Compliance Checking

Lattice-based compliance checks event log streams against a process specification by mapping state transitions to a partial order structure.

### 1.1 Witness Join-Semilattice
We define the witness space as a bounded join-semilattice $(W, \sqsubseteq, \sqcup, \bot, \top)$ where:
- $W$ is the set of all witness states.
- $\sqsubseteq$ is the partial order representing evidence inclusion and refinement.
- $\sqcup$ is the join operator representing evidence union.
- $\bot$ is the bottom element representing zero evidence (initial state).
- $\top$ is the top element representing conflict or non-compliance.

The join operator $\sqcup$ is idempotent, commutative, associative, and compatible with the partial order:
- **Idempotency**: $\forall w \in W, \quad w \sqcup w = w$
- **Commutativity**: $\forall w_1, w_2 \in W, \quad w_1 \sqcup w_2 = w_2 \sqcup w_1$
- **Associativity**: $\forall w_1, w_2, w_3 \in W, \quad (w_1 \sqcup w_2) \sqcup w_3 = w_1 \sqcup (w_2 \sqcup w_3)$
- **Order Compatibility**: $\forall w, u \in W, \quad w \sqsubseteq u \iff w \sqcup u = u$

For more details on semilattice algebras and properties, see [Witness Lattices Specification](file:///Users/sac/process-intelligence/sources/wasm4pm-compat/witness-lattices.md) and [Type-Law Atlas](file:///Users/sac/process-intelligence/sources/wasm4pm-compat/type-law-atlas.md).

### 1.2 Transition Monotonicity
Let $\Sigma$ be the alphabet of activities. The transition update function is defined as $\delta: W \times \Sigma \to W$.

We state the **Monotonicity Axiom (Axiom 2)**:
$$\forall w \in W, \forall a \in \Sigma, \quad w \sqsubseteq \delta(w, a)$$

This is mathematically equivalent to:
$$\forall w \in W, \forall a \in \Sigma, \quad w \sqcup \delta(w, a) = \delta(w, a)$$

The monotonicity axiom ensures that witness states only move upwards in the partial order towards $\top$, and never retreat to a lower state. 

#### Theorem (Top absorbing state)
The conflict state $\top$ is an absorbing state of the transition system:
$$\forall a \in \Sigma, \quad \delta(\top, a) = \top$$

#### Proof
By the definition of a bounded join-semilattice, $\top$ is the unique maximum element of the lattice:
$$\forall w \in W, \quad w \sqsubseteq \top$$
By applying Axiom 2, we have:
$$\top \sqsubseteq \delta(\top, a)$$
Since $\top$ is the maximum element, the only element $w \in W$ that satisfies $\top \sqsubseteq w$ is $\top$.
Thus, $\delta(\top, a) = \top$ for all $a \in \Sigma$. $\blacksquare$

Once a trace triggers a conflict, the witness state reaches $\top$ and remains there permanently, indicating non-compliance. For runtime verification guidelines, see [Lattice Monotonicity Verification](file:///Users/sac/process-intelligence/doctrine/lattice-monotonicity-verification.md).

## 2. Mathematical Formulation of Trace-Based Compliance Checking

Trace-based compliance checks if a sequence of observed events $\sigma = \langle e_1, \dots, e_n \rangle$ belongs to the language $\mathcal{L}(M)$ generated by a process model $M$.

### 2.1 State Space and Alignment Complexity
Let $(S, T, F, m_0, S_f)$ be the transition system of the process model.
Trace replay searches for a path of transitions $\tau = \langle t_1, \dots, t_m \rangle$ from the initial state $m_0$ to some final state $m_f \in S_f$ such that the visible labels of $\tau$ match $\sigma$.

In traditional trace-based compliance (such as alignment algorithms):
- Finding the optimal alignment requires searching a state space whose size is proportional to $|S| \times |\sigma|$, where $|S|$ is the state space size of the model and $|\sigma|$ is the trace length.
- If we do offline search (like A*), the memory requirements grow unbounded with trace length because the search tree of path histories must be retained in memory.
- In contrast, lattice-based compliance maintains only the current witness $W_{\text{current}} \in W$. The transition function $\delta(W_{\text{current}}, a)$ is evaluated in $O(1)$ space with respect to trace length, eliminating memory leaks and interpreter pauses.

## 3. Trace-to-Lattice Compliance Equivalence Theorem

This section proves that lattice-based compliance checking is sound and complete with respect to trace-based language acceptance.

### 3.1 Trace-to-Lattice Compliance Equivalence Theorem
Let $M$ be a process model represented as a deterministic transition system $M = (S, \Sigma, \delta_S, s_0, S_f)$ with language $\mathcal{L}(M) \subseteq \Sigma^*$. Let $(W, \sqsubseteq, \sqcup, \bot, \top)$ be a witness join-semilattice, $\delta: W \times \Sigma \to W$ be the witness transition function, and $\phi: W \to \{\text{True}, \text{False}\}$ be a terminal acceptance function.

Suppose there exists an abstraction homomorphism $\alpha: S \to W$ satisfying:
1. **Initial Consistency**: $\alpha(s_0) = \bot$.
2. **Transition Homomorphism**: For all reachable states $s \in S$ and events $a \in \Sigma$:
   - If $\delta_S(s, a) = s'$, then $\delta(\alpha(s), a) = \alpha(s')$.
   - If $\delta_S(s, a)$ is undefined, then $\delta(\alpha(s), a) = \top$.
3. **Acceptance Equivalence**: For all reachable states $s \in S$, $\phi(\alpha(s)) = \text{True} \iff s \in S_f$.
4. **Top Consistency**: For all $s \in S$, $\alpha(s) \neq \top$.

Then, for any trace $\sigma = \langle e_1, \dots, e_n \rangle \in \Sigma^*$, the trace is accepted by the process model ($\sigma \in \mathcal{L}(M)$) if and only if the final witness $W_n = \delta(\dots \delta(\bot, e_1) \dots, e_n) \neq \top$ and $\phi(W_n) = \text{True}$.

### 3.2 Inductive Proof

We prove the equivalence by induction on the length of the trace $k = |\sigma|$.

Let $\delta_S^*(s, \sigma)$ represent the multi-step transition function in $M$, and let $\delta^*(w, \sigma)$ represent the multi-step transition function in $W$.

#### Base Case ($k = 0$, $\sigma = \epsilon$)
For the empty trace $\sigma = \epsilon$:
- The final state in $M$ is $s_0$. The trace is accepted if and only if $s_0 \in S_f$.
- The final witness in $W$ is $W_0 = \bot$.
- By Initial Consistency (Property 1), $\alpha(s_0) = \bot = W_0$.
- Since $s_0$ is a valid state, by Top Consistency (Property 4), $W_0 \neq \top$.
- By Acceptance Equivalence (Property 3), $\phi(W_0) = \phi(\alpha(s_0)) = \text{True} \iff s_0 \in S_f$.
Thus, the theorem holds for $k = 0$.

#### Inductive Step
Assume the theorem holds for all traces of length $k$. That is, for any trace $\sigma_k$ of length $k$:
- If $\delta_S^*(s_0, \sigma_k) = s_k$ is defined, then the witness state is $W_k = \delta^*(\bot, \sigma_k) = \alpha(s_k) \neq \top$.
- If $\delta_S^*(s_0, \sigma_k)$ is undefined, then $W_k = \delta^*(\bot, \sigma_k) = \top$.

Let $\sigma_{k+1} = \sigma_k \cdot a$ be a trace of length $k+1$, where $a \in \Sigma$.

**Case A: $\sigma_k \cdot a \in \mathcal{L}(M)$ (or is a valid prefix)**
If $\sigma_k \cdot a$ is a valid prefix in $M$, then $\delta_S^*(s_0, \sigma_k) = s_k$ is defined, and $\delta_S(s_k, a) = s_{k+1}$ is defined.
By the induction hypothesis:
$$W_k = \alpha(s_k) \neq \top$$
By Transition Homomorphism (Property 2), since $\delta_S(s_k, a) = s_{k+1}$, we have:
$$W_{k+1} = \delta(W_k, a) = \delta(\alpha(s_k), a) = \alpha(s_{k+1})$$
By Top Consistency (Property 4), since $s_{k+1} \in S$, we have:
$$W_{k+1} = \alpha(s_{k+1}) \neq \top$$
Furthermore, if $\sigma_{k+1}$ is a complete trace (length $n = k+1$), then:
$$\sigma_{k+1} \in \mathcal{L}(M) \iff s_{k+1} \in S_f \iff \phi(\alpha(s_{k+1})) = \text{True} \iff \phi(W_{k+1}) = \text{True}$$
Thus, the theorem holds.

**Case B: $\sigma_k \cdot a$ is not a valid prefix in $M$**
There are two sub-cases:
1. **$\sigma_k$ was already invalid**:
   By the induction hypothesis, $W_k = \top$.
   By the Top absorbing state theorem:
   $$W_{k+1} = \delta(W_k, a) = \delta(\top, a) = \top$$
   Thus, $W_{k+1} = \top$, which is correct as the trace remains invalid.
2. **$\sigma_k$ was valid, but $a$ is an invalid transition**:
   Here, $\delta_S^*(s_0, \sigma_k) = s_k$ is defined, but $\delta_S(s_k, a)$ is undefined.
   By the induction hypothesis:
   $$W_k = \alpha(s_k) \neq \top$$
   By Transition Homomorphism (Property 2), since $\delta_S(s_k, a)$ is undefined, we have:
   $$W_{k+1} = \delta(\alpha(s_k), a) = \top$$
   Thus, $W_{k+1} = \top$, signaling non-compliance.

In all cases, the inductive step holds.
By mathematical induction, the theorem is proved. $\blacksquare$

## 4. Tamper Resistance and Cryptographic Verification

A core operational advantage of lattice-based compliance checking is the ease of cryptographic witness attestation.

### 4.1 BLAKE3 Hash Chaining
As the guest WASM engine processes events, it builds an immutable hash chain of the witness state trajectory. Let the event stream be $e_1, e_2, \dots, e_n$ producing witness states $W_1, W_2, \dots, W_n$.
- The initial hash $H_0$ is computed as:
  $$H_0 = \text{BLAKE3}(\text{Process Model ID} \parallel \bot)$$
- For each step $k \in \{1, \dots, n\}$:
  $$H_k = \text{BLAKE3}(H_{k-1} \parallel e_k \parallel W_k)$$

### 4.2 Signature and Attestation
Upon trace termination, the final hash $H_n$ and witness $W_n$ are bundled into a verification receipt. The guest engine signs the receipt using Ed25519:
$$\text{Receipt} = (H_n, W_n, \operatorname{Sign}_{\text{Ed25519}}(H_n \parallel W_n))$$

Any attempt to tamper with the event sequence (e.g., injecting, reordering, or deleting events) changes the intermediate witness states and event inputs, breaking the BLAKE3 hash chain. This provides absolute mathematical proof of process execution integrity that trace-based post-hoc replays cannot match.
