# Experiment: ggen Projection Validation

This experiment validates process projections generated by the `ggen` (Ostar generative pipeline) tool. The projection extracts a target process model (Petri Net or Process Tree) from a raw event log based on specific filtering rules and schema assertions.

## 1. ggen Projection JSON Validation Schema

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "title": "GgenProjectionOutput",
  "type": "object",
  "properties": {
    "projection_id": { "type": "string" },
    "source_log_hash_sha256": { "type": "string", "pattern": "^[0-9a-fA-F]{64}$" },
    "target_model_type": { "enum": ["PetriNet", "ProcessTree", "DFG"] },
    "filtering_parameters": {
      "type": "object",
      "properties": {
        "start_date": { "type": "string", "format": "date-time" },
        "end_date": { "type": "string", "format": "date-time" },
        "selected_activities": {
          "type": "array",
          "items": { "type": "string" }
        }
      },
      "required": ["selected_activities"]
    },
    "projection_result": {
      "type": "object",
      "properties": {
        "nodes_count": { "type": "integer" },
        "edges_count": { "type": "integer" },
        "fitness_score": { "type": "number", "minimum": 0.0, "maximum": 1.0 },
        "model_structure": { "type": "object" }
      },
      "required": ["nodes_count", "edges_count", "fitness_score", "model_structure"]
    }
  },
  "required": ["projection_id", "source_log_hash_sha256", "target_model_type", "filtering_parameters", "projection_result"]
}
```
