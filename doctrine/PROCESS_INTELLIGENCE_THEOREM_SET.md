# Process Intelligence Theorem Set

## T1 — Consequence Conservation Theorem
*No enterprise consequence is valid without a receipted process trace.*

Informal: If an output cannot be traced to a lawful process execution with a verified receipt, it is not enterprise consequence — it is output.

## T2 — Admission Prerequisite Theorem
*Raw evidence cannot participate in conformance checking without admission.*

Informal: The admission gate is not optional. Bypassing admission produces untrusted conformance scores.

## T3 — Replay Completeness Theorem
*A process that cannot be replayed from its receipts has not demonstrated lawfulness.*

Informal: Receipts must be sufficient to reconstruct the execution. A receipt that cannot drive replay is incomplete.

## T4 — Bounded Motion Theorem (CONSTRUCT8)
*A delta exceeding the bounded maximum is not a large change — it is an unbounded change and must be split.*

Informal: Need9 is not a style preference. It is a boundary law.

## T5 — Object-Centric Supremacy Theorem
*Single-case-ID process models are a degenerate special case of object-centric models and produce structurally incorrect conformance when multiple object types interact.*

Informal: If your process involves orders, items, customers, and payments, a flat XES trace loses all object interactions.
