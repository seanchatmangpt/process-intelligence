# Process Intelligence Glossary

## Core Terms

**Process Intelligence** — The discipline of deriving lawful, receipted consequence from observable process evidence. Not AI analytics. Not workflow automation.

**Process Evidence** — Raw observational data that can be mined into a conforming object-centric process model.

**Consequence Conservation** — The principle that enterprise consequence cannot be manufactured from outputs alone; it requires lawful process evidence.

**Receipt** — A cryptographically-bound artifact that proves a specific process transition occurred lawfully.

**Admission Gate** — The boundary at which raw evidence is structurally validated before being admitted for process analysis.

**Conformance** — The measurable alignment between an observed process and its declared model, expressed as fitness, precision, simplicity, and generalization.

**Object-Centric Process** — A process model in which multiple interacting object types (not a single case ID) define the process space.

**Bounded Motion** — The principle that changes to process state must be constrained to a lawful maximum delta (CONSTRUCT8: max 8 primary units per delta).

**Hook** — A lifecycle checkpoint that must fire before a transition may be treated as lawful consequence.

**Replay** — The process of re-executing a recorded event log against a process model to verify that the original execution was lawful.
